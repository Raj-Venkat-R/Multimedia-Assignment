# 🍓 SweetBerry Shop

A creative animated advertisement web page for a strawberry-themed dessert shop.

This project is a simple front-end website built using **HTML and CSS animations**.  
It features a floating strawberry logo with sparkling effects and an attractive promotional layout.

---

## ✨ Features

- 🍓 Floating animated strawberry logo  
- ✨ Sparkle animation around the logo  
- 🎨 Gradient advertisement-style background  
- 🎉 Promotional offer section  
- 🖱️ Hover effect on button  
- 📱 Clean and simple design
